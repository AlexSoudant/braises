# React + Vite à la place du JS natif sans build

La première version de Braises était en JS natif, sans étape de build, servie telle quelle par GitHub Pages. On la réécrit en React + TypeScript, construit avec Vite (vite-plugin-pwa pour le hors ligne) et publié par GitHub Actions. C'est un choix de l'utilisateur, qui veut une base React pour faire grandir l'app. On accepte en échange une étape de build et une chaîne CI. L'ancienne version reste archivée sur la branche `prototype`. Les données de cette version ne sont pas reprises.
